# Scribeberry Staff releases

Public installers for the **Scribeberry Staff** EMR (Linux AppImage + Android APK).

Source code stays private in `Scribeberry/Scribeberry-app`. This repo only holds
GitHub Releases that clinics can download without authentication.

- Latest: https://github.com/Scribeberry/staff-releases/releases/latest
- The in-app update banner checks this repo’s release API.
